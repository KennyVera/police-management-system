# Evidencias ficticias (demo)

Imagenes **sinteticas** generadas para pruebas del Sistema de Gestion Policial.
No son fotografias reales ni material de casos reales.

## Uso
Adjuntarlas manualmente como "Archivos iniciales" al crear/editar un parte
(Agente Operativo), o en el modulo de multimedia.

## Origen
No provienen de Pinterest ni de bancos de imagenes con derechos de terceros.
Son placeholders generados localmente (Pillow) con etiqueta visible DEMO / FICTICIA.
